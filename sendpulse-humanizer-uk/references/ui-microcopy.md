# UI-мікрокопі українською (SaaS)

Плейбук для інтерфейсних текстів: кнопки, помилки, порожні стани, онбординг, підказки, плейсхолдери,
листи-сповіщення. Тут найбільше машинних кальок, бо UI зазвичай перекладають з англійської чи
російської — швидко й пачками.

Загальний принцип: **коротко, дією, без води, без суржику.** Користувач читає інтерфейс на бігу.
Кожне зайве слово — тертя.

## 2. Тон і звертання

- **«Ви» за замовчуванням** для B2B SaaS (SendPulse). У тексті інтерфейсу «ви» пишемо з малої
  літери (велика — лише в персональних листах як знак пошани, і то за рішенням бренду). Тримай
  один регістр по всьому продукту — не змішуй «ви» і «ти».
- **Кличний відмінок у звертанні на ім'я:** «Вітаємо, Оксано!», «Дмитре, ваш звіт готовий».
  Якщо система підставляє ім'я через змінну (`{{name}}`) і не вміє відмінювати — або переформулюй
  без прямого звертання («Ваш звіт готовий»), або додай кому-звертання так, щоб називний не різав
  око («Вітаємо! Ваш звіт готовий»).
- **Без надмірної ввічливості й без панібратства.** «Будь ласка» — доречне в проханні («Зачекайте,
  будь ласка»), не в кожному рядку.
- **Активний стан, теперішній/наказовий час:** «Збережіть зміни», «Файл завантажено» — не
  «Зміни повинні бути збережені».

## 3. Кнопки

- **Дієслово, 1–3 слова.** «Зберегти», «Створити розсилку», «Надіслати тест».
- Кнопка = дія, яку вона виконує. Не «ОК» там, де можна «Видалити» / «Зберегти».
- **Пара дій:** головна — дія, друга — «Скасувати». Не «Так/Ні» до питання «Видалити запис?» —
  краще «Видалити» / «Скасувати».
- Без крапки в кінці. Без Title Case: «Створити кампанію», не «Створити Кампанію».

---

## 4. Повідомлення про помилки

Формула: **що сталося + чому (якщо корисно) + що зробити.** Без звинувачень, без кодів у обличчя
користувачу, без паніки.

| Погано | Добре |
|---|---|
| Помилка 500 | Не вдалося зберегти. Спробуйте ще раз за хвилину. |
| Невірний пароль | Пароль неправильний. Перевірте розкладку та Caps Lock. |
| Ви ввели невірні дані | Перевірте формат email — має бути на кшталт name@example.com. |
| Поле обов'язкове для заповнення | Заповніть це поле. |
| Файл занадто великий | Файл завеликий. Максимум — 5 МБ. |
| Щось пішло не так | Не вдалося завантажити список. Перевірте з'єднання й повторіть. |

- «Невірний» → «неправильний» / «хибний» (невірний = невідданий).
- Не лякай («Критична помилка!»), не вибачайся зайве. Одне «Вибачте» на справді серйозний збій.

## 5. Порожні стани (empty states)

Не «Немає даних». Скажи, що це і що зробити далі:
- «Тут з'являться ваші розсилки. Створіть першу — це займе кілька хвилин.» + кнопка «Створити
  розсилку».
- «Список контактів порожній. Імпортуйте контакти з файлу або додайте вручну.»

---

## 6. Онбординг і підказки (tooltips)

- Одна думка на підказку. «Тут можна сегментувати контактів за поведінкою» — досить.
- Без «Давайте розглянемо», «Крок за кроком занурмося». Одразу до діла.
- Плейсхолдери в полях — приклад формату, не інструкція: `name@example.com`, а не «Введіть сюди
  вашу електронну адресу».

---

## 7. Множина (плюралізація) — 3 форми

Українська має **три** форми множини. Локалізаційні рушії (ICU MessageFormat, i18next тощо) мають
`one / few / many`. Ніколи не лишай «5 файл» чи «1 файли».

| Число | Форма | Приклад |
|---|---|---|
| 1, 21, 31… (крім 11) | one | 1 файл, 21 контакт, 1 лист |
| 2–4, 22–24… (крім 12–14) | few | 2 файли, 3 контакти, 4 листи |
| 5–20, 25–30… | many | 5 файлів, 11 контактів, 100 листів |

Приклад ICU:
```
{count, plural,
  one {# контакт}
  few {# контакти}
  many {# контактів}
  other {# контакту}}
```
(форма `other` потрібна для дробових: «1,5 бала».)

## 8. Числа, дати, валюта, формати

- **Десятковий роздільник — кома:** 1 234,56 (не 1,234.56). Тисячі — нерозривний пробіл.
- **Дата:** 22.07.2026 або «22 липня 2026». Місяць у даті — родовий відмінок: «22 липня», не
  «22 липень».
- **Час:** 24-годинний, 14:30 (не 2:30 PM).
- **Валюта:** 250 грн або 250 ₴; символ після числа з пробілом. Долари — $250 або 250 доларів.
- **Відсотки:** 25 % (з нерозривним пробілом) — або 25% за стилем бренду; головне — однаково скрізь.

---

## 9. Змінні та плейсхолдери — не чіпати

У текстах трапляються службові змінні: `{{name}}`, `{{unsubscribe_url}}`, `{{current_year}}`,
`%s`, `{0}`, `:count`. **Ніколи не перекладай і не змінюй їх** — тільки текст навколо. Стеж, щоб
відмінок слів навколо змінної працював для типових підстановок, або переформулюй так, щоб змінна
стояла в називному («Ваш план: {{plan}}», а не «Ви на {{plan}}»).

## 10. Чек-лист UI-тексту

- [ ] Стандартні дієслова зі словника (Скасувати, Надіслати, Увімкнути, За замовчуванням)
- [ ] Жодного суржику / активного дієприкметника
- [ ] Кнопки — дія, 1–3 слова, без крапки, без Title Case
- [ ] Помилки: що сталося + що зробити; «неправильний», не «невірний»
- [ ] Порожні стани пояснюють наступний крок
- [ ] Кличний відмінок у звертанні на ім'я
- [ ] Множина у 3 формах (one/few/many)
- [ ] Кома як десятковий роздільник; дата з місяцем у родовому
- [ ] Змінні `{{...}}` / `%s` / `{0}` не зачеплено
