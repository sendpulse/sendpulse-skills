# Словник русизмів, кальок і суржику

Найшвидший спосіб зняти «російський слід» з українського тексту — прогнати його по цьому словнику.
Машинний переклад із російської (а LLM генерує українську фактично через російські внутрішні
уявлення) майже завжди лишає ці конструкції. Для українського читача вони — найпомітніший маркер
неприродності, помітніший за будь-яке AI-кліше.

**Як користуватися:** шукай ліву колонку в тексті, заміняй на праву. Права колонка часто дає кілька
варіантів — обирай за контекстом. Замінюй завжди, крім цитат і фіксованих юридичних формулювань.

**Регістр за замовчуванням — прагматичний сучасний стандарт.** Прибираємо суржик і кальки, але не
женемося за крайнім пуризмом. Пуристичні альтернативи винесено в окремий розділ 8 — застосовуй їх,
тільки якщо користувач просить суворіший регістр.

## 2. Активні дієприкметники на `-учий / -ючий / -ащий / -ящий`

Це найсильніший маркер машинного перекладу з російської. У живій українській активних
дієприкметників теперішнього часу практично немає. Заміняй одним із трьох способів:

**Спосіб 1 — підрядне «який + дієслово».**
**Спосіб 2 — прикметник (`-льний / -ний / -івний / -чий`).**
**Спосіб 3 — іменник.**

| Дієприкметник (калька) | Правильно |

| існуючий | наявний; який існує; чинний |
| діючий (закон, договір) | чинний |
| діючий (механізм) | робочий; наявний |
| керуючий | керівний; той, хто керує; керівник; управитель |
| завідуючий | завідувач |
| командуючий | командувач |
| виконуючий обов'язки | виконувач обов'язків; в. о. |
| головуючий | головуючий → голова (зборів); той, хто головує |
| зростаючий | дедалі більший; який зростає; щоразу вищий |
| спадаючий | спадний; який спадає |
| домінуючий | панівний; домінантний; переважний |
| вражаючий | разючий; приголомшливий; який вражає |

## 7. Слова-пастки: НЕ «виправляй» правильну українську на кальку

LLM, знімаючи один шар, часто повертає інший: «виправляє» живе українське слово на звичніший
російський відповідник. Це помилка. Ці слова правильні — лишай:

- **наразі** (= зараз, поки що) — правильне, не міняй на «на даний момент».
- **позаяк, адже, оскільки** — правильні сполучники, не міняй на «так як».
- **щойно** (= тільки-но) — правильне.
- **втім, проте, однак** — правильні, не міняй на «тим не менше».
- **дедалі** (дедалі більше) — правильне, не міняй на «все більше».
- **лише, тільки** — обидва правильні.
- **зокрема** — правильне, не міняй на «в тому числі».
- **застосунок, посилання, обліковий запис, вкладення** — коректні UI-терміни.
- **кличний відмінок** (Оксано, друже) — це НЕ помилка, а норма. Не «виправляй» на називний.
- **фемінітиви** (авторка, розробниця) — норма сучасної мови, не чоловічий рід «за замовчуванням».

## 8. Пуристичний шар (опційно)

Застосовуй, ТІЛЬКИ якщо користувач просить суворіший / «чистіший» регістр. За замовчуванням ці
заміни НЕ роби — обидва варіанти прийнятні в сучасній мові.

| Ужиткове | Пуристична альтернатива |
|---|---|
| додаток (застосунок) | застосунок |
| посилання | покликання |
| фотографія | світлина |
| гелікоптер / вертоліт | гвинтокрил |
| відсоток | відсоток (уже питоме) |
| екран | екран / зображник (рідко) |
| мапа / карта | мапа |
| файл / документ | (лишати; питомого замінника немає) |

Не перегинай: надмірний пуризм у SaaS-інтерфейсі так само шкодить, як і суржик, — користувач може
не впізнати «покликання» замість звичного «посилання».
