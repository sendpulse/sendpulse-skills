# Email Types — Section Sets, Goals & Rules

> Read this after detecting the email type. Each type has a different goal, structure, tone, and
> set of "must-have" blocks. Build only the relevant sections. Three broad categories drive the
> rules: **selling** (promo, trigger), **transactional** (order, account), **educational/relational**
> (welcome, newsletter, reactivation).

## 1. Quick type detector

| User says… | Type |
|---|---|
| sale, discount, % off, Black Friday, promo, offer, new collection | **promo** |
| welcome, thanks for signing up, get started, onboarding | **welcome** |
| digest, weekly, monthly, news, roundup, blog | **newsletter** |
| order, receipt, confirmation, shipped, invoice, password, OTP | **transactional** |
| we miss you, come back, inactive, still interested | **reactivation** |
| left in cart, didn't finish, abandoned, almost done | **trigger** |
| course, lesson, guide, tips, how-to, tutorial | **educational** |

When ambiguous, ask one short question or default to the closest selling/relational type.

## 2. Promo / Sale
**Goal:** drive a click to a product/offer. **Tone:** energetic, benefit-led, urgency where honest.
**Sections:** preheader → header/logo → hero (offer + headline) → 1 primary CTA → product cards
(optional) → secondary CTA (optional) → social (optional) → footer.
**Rules:** one dominant offer and one primary CTA above the fold. Show the discount/value visually
in the hero. Real urgency only (end date, stock) — never fake countdowns. Price/terms legible.
Keep copy short; let the image and CTA carry it.

## 3. Welcome / Onboarding
**Goal:** set expectations, first action, build trust. **Tone:** warm, human, brief.
**Sections:** preheader → header/logo → hero/greeting → intro text (1–2 short paragraphs) →
features (3-col: what they get) → 1 CTA (the single most important first action) → social → footer.
**Rules:** personalize with `{{name}}`. One primary action, not a menu. Reassure (no spam, how to
unsubscribe). Often the highest-engagement email — make the CTA count.

## 4. Newsletter / Digest
**Goal:** inform, nurture, recirculate to content. **Tone:** editorial, scannable.
**Sections:** preheader → header/logo → optional hero → article digest blocks (image + title +
1–2 line teaser + "read more") → section dividers → social → footer.
**Rules:** consistent repeating block per article. 3–6 items max. Each item has its own link
(with its own UTM `content` value). Strong section hierarchy via headings and separators.

## 5. Transactional / Order
**Goal:** confirm/inform reliably. **Tone:** clear, factual, minimal marketing.
**Sections:** preheader → header/logo → confirmation headline → order/transaction details table →
1 CTA ("view order"/"track") → support contact → footer.
**Rules:** facts first, no hero hard-sell. Order details in a clean table (item, qty, price, total).
Keep promotional content minimal or absent (deliverability & legal expectations differ from bulk).
Include order #, date, and a support link. Never omit unsubscribe if sent through the bulk system.

## 6. Reactivation / Win-back
**Goal:** re-engage dormant subscribers or let them cleanly opt out. **Tone:** honest, a little
personal. **Sections:** preheader → header/logo → hero ("we miss you" + incentive) → short reason
to return → 1 CTA → "update preferences / unsubscribe" line → footer.
**Rules:** offer a real reason (incentive, what's new). Make preference-update and unsubscribe easy
and visible — re-permission is healthier than spam complaints. Good A/B candidate (incentive vs none).

## 7. Trigger / Abandoned cart
**Goal:** recover an in-progress action. **Tone:** helpful nudge, low pressure.
**Sections:** preheader → header/logo → reminder headline → product card(s) of the abandoned items →
1 CTA ("complete your order") → reassurance (returns/support) → footer.
**Rules:** show exactly what they left. Single clear CTA back to the cart. Optional incentive in a
follow-up, not the first nudge. Time-sensitive — usually part of an automation.

## 8. Educational / Nurture
**Goal:** teach, build authority, soft-guide to a next step. **Tone:** clear, generous, expert.
**Sections:** preheader → header/logo → lesson headline → body (steps/tips, well-spaced) →
1 CTA (next lesson/resource) → footer.
**Rules:** one concept per email. Use headings, numbered steps, short paragraphs. CTA is a logical
next step, not a hard sell. Great in sequences (course drip).

---

## 9. Category rules

**Selling (promo, trigger):** one offer, one primary CTA, value visible fast, honest urgency,
strong hero. Heavier use of imagery and color. A/B test subject + hero + CTA.

**Transactional (order, account, OTP):** clarity over persuasion, facts in tables, minimal
marketing, fast and reliable. Different deliverability expectations — keep it lean.

**Educational/relational (welcome, newsletter, reactivation, nurture):** human tone, scannable
structure, consistent repeating blocks, clear single next step, personalization, easy preference
control. Optimized for long-term engagement, not a single click.
